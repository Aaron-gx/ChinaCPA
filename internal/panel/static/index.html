模型发布
对外统一模型标识符 ➔ 上游集群拓扑映射

发布列表 $1 = ¥

网关端点仅对外暴露在此配置的模型定义：单一路由模型名 ➔ 映射至多个上游渠道。调度策略可选「优先级容灾」（默认按次序执行主备容灾切换）或「轮询负载均衡」（多渠道均匀分担流量）；渠道内部多实例默认启用会话亲和锁定（保持上游 Prompt Cache 高命中率）。客户端仅需在请求体指定 {"model":"路由模型名"} 即可；对话模型定价用于调用成本审计，多模态模型支持按次计费。若未配置任何发布模型，网关默认直接透传所有内部模型。
支持图片与视频生成模型接入（如豆包 Seedream / Seedance 引擎）：图片标准端点 POST /v1/images/generations，视频异步生成支持火山方舟任务协议 POST /api/v3/contents/generations/tasks。
